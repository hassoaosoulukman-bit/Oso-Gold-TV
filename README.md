# Oso Gold TV

تطبيق أندرويد (Kotlin + Media3/ExoPlayer) بتصميم "البوصلة الكونية" الأسود والذهبي.

## البناء التلقائي على GitHub
1. أنشئ مستودعاً جديداً على GitHub وارفع **كل** محتويات هذا المجلد (بما فيه المجلد المخفي `.github`).
2. بمجرد الرفع يبدأ GitHub Actions تلقائياً (تبويب **Actions** ← *Build Oso Gold TV APK*).
3. بعد انتهاء البناء (حوالي 3–6 دقائق) افتح التشغيل الناجح ونزّل الملف **OsoGoldTV-apk** من قسم *Artifacts*.
4. فكّ الضغط وثبّت `OsoGoldTV.apk` على الجوال (يلزم السماح بالتثبيت من مصادر غير معروفة).

> لإصدار رابط تنزيل ثابت: أنشئ وسماً (tag) مثل `v1.0.0` وسيُرفق الـ APK تلقائياً في صفحة *Releases*.

## كلمة السر
- كلمة السر الافتراضية: **1234** — غيّرها من *الإعدادات ← كلمة السر*.
- تُطلب مرة واحدة فقط، ثم تُحفظ حالة الدخول. عند تغيير كلمة السر تُطلب مرة أخرى في الفتح التالي.

## الفيديو الترحيبي
- بعد كلمة السر يعمل الفيديو الترحيبي بملء الشاشة مع زر **تخطي**.
- من *الإعدادات ← الفيديو الترحيبي*: اختر فيديو من المعرض أو صوّر فيديو جديداً.
- إن لم تختر فيديو، يعمل مقطع افتتاحي ملكي متحرك مدته 30 ثانية.
- (اختياري) ضع ملفاً باسم `welcome.mp4` في `app/src/main/res/raw/` ليكون الفيديو الافتراضي.

## القوائم (M3U)
الروابط الافتراضية من مشروع iptv-org ويمكن تغييرها من *الإعدادات ← مصادر القوائم*.
